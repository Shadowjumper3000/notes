# Formal Language Theory

## Overview

Formal language theory studies languages as mathematical objects defined by explicit rules. It provides a formal framework for describing, recognizing, and generating structured sequences — both for artificial (programming) languages and as a model for certain aspects of natural language.

## The Chomsky Hierarchy

Noam Chomsky (1956) classified formal grammars into four levels of increasing expressivity:

| Type | Name | Rule Form | Automaton | Example | Natural Language? |
|---|---|---|---|---|---|
| **Type 3** | Regular | $A \to aB$, $A \to a$ | Finite-state automaton (FSA) | Regex, FST | No (cannot model center-embedding) |
| **Type 2** | Context-Free | $A \to \gamma$ | Pushdown automaton (PDA) | CFG, most programming languages | Partial (cross-serial dependencies fail) |
| **Type 1** | Context-Sensitive | $\alpha A \beta \to \alpha \gamma \beta$ | Linear-bounded automaton | Some Swiss German constructions | Possibly (some constructions require it) |
| **Type 0** | Unrestricted | $\alpha \to \beta$ | Turing machine | Any recursively enumerable set | Over-generates |

Each level properly contains the previous one: Regular $\subset$ Context-Free $\subset$ Context-Sensitive $\subset$ Recursively Enumerable.

## Regular Languages (Type 3)

Generated by regular grammars or regular expressions. Recognized by finite-state automata. Used in NLP for:

- **Tokenization**: Finite-state transducers for word segmentation.
- **Morphological analysis**: Two-level morphology (Koskenniemi) uses finite-state rules.
- **Text normalization**: Pattern matching, spelling correction, number expansion.
- **Named entity recognition**: Gazetteer matching and pattern-based extraction.

**Limitation**: Regular languages cannot model nested structures (e.g., parentheses matching, center-embedded clauses like "The rat the cat ate was white").

## Context-Free Grammars (Type 2)

CFGs consist of:

- A set of nonterminals $N$.
- A set of terminals $\Sigma$.
- A start symbol $S \in N$.
- Production rules $A \to \alpha$ where $A \in N$ and $\alpha \in (N \cup \Sigma)^*$.

**Example**:
```
S  → NP VP
NP → Det N | Det N PP
VP → V NP | V NP PP
PP → P NP
```

CFGs can model recursive structures like relative clauses and prepositional phrase attachment. They are the basis for [[NLP Libraries and Pipelines|syntactic parsing]] in many NLP systems.

**Limitation**: Certain natural language constructions (e.g., Swiss German cross-serial dependencies) require context-sensitive power. For most practical purposes, CFGs augmented with features (feature-structure grammars, HPSG, LFG) or probabilistic weights (PCFG) are sufficient.

## Probabilistic Context-Free Grammars (PCFG)

A PCFG adds probabilities to productions such that $\sum_\alpha P(A \to \alpha) = 1$ for each nonterminal $A$. The probability of a tree $T$ is the product of rule probabilities:

$$
P(T) = \prod_{A \to \alpha \in T} P(A \to \alpha)
$$

PCFGs are learned from treebanks (e.g., Penn Treebank) via MLE. They are used in [[Statistical Language Models|statistical parsing]].

## Beyond Context-Free

Linguistic phenomena that challenge CFGs:

- **Copy dependencies**: $ww$ (e.g., "respectively" constructions in English).
- **Cross-serial dependencies**: Swiss German subordinate clauses.
- **Reduplication**: Productive in many languages (e.g., "big big" = "very big").

Evidence suggests natural language requires at least mildly context-sensitive grammars (e.g., Tree-Adjoining Grammars, Combinatory Categorial Grammars).

## Applications in NLP

### Parsing
- **Constituency parsing**: Building phrase-structure trees (CFG/PCFG).
- **Dependency parsing**: Representing grammatical relations directly; more flexible than constituency and more widely adopted in modern [[NLP Libraries and Pipelines|libraries like spaCy]].

### Grammar Induction
Learning grammars from unlabeled text (unsupervised parsing) — an active research area with limited practical success.

### Language Modeling
While n-gram and neural models have dominated, formal grammars provide a structured prior that can enforce grammaticality during generation.

### Machine Translation
Synchronous CFGs (SCFG) model translation as parallel tree transduction (Hiero, syntax-based SMT).

## Relationship to Statistical Approaches

Formal language theory represents the [[Two Ways of Thinking About Language|symbolic view of language]]: language is a discrete, combinatorial system governed by rules. Its limitations — brittleness, need for manual grammar engineering, difficulty with gradience — motivated the shift to [[Statistical Language Models|statistical models]].

However, modern NLP increasingly combines formal and statistical methods:

- **Neural parsing**: Use LSTM/transformer encoders with structured prediction (CRF, CKY).
- **Grammar induction with neural networks**: Learning latent tree structures from data.
- **Differentiable CKY**: End-to-end learning of PCFGs via backpropagation.
