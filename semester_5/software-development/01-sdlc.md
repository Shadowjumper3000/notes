# Software Development Life Cycle (SDLC)

## 1. Planning
- Define objectives, scope, and high-level goals  
- Identify stakeholders and resources  
- Conduct feasibility analysis (technical, financial, operational)  
- Risk assessment and mitigation strategies  
- Establish project timelines and milestones  

## 2. Requirements
- Gather functional and non-functional requirements  
- Document user stories and use cases  
- Define acceptance criteria  
- Prioritize features (e.g., MoSCoW, Kano model)  
- Requirements validation with stakeholders  

## 3. Design
- High-level architecture (system, modules, data flow)  
- Detailed design (UI/UX mockups, database schema, APIs)  
- Define technology stack and standards  
- Security and scalability considerations  
- Review and approval of design artifacts  

## 4. Development
- Set up development environment and CI/CD pipelines  
- Implement features based on requirements and design  
- Follow coding standards and best practices  
- Perform peer code reviews  
- Maintain documentation alongside implementation  

## 5. Testing
- Unit, integration, system, and acceptance testing  
- Automated test suites and manual test cases  
- Performance, security, and regression testing  
- Bug tracking and resolution workflow  
- Validate against requirements and acceptance criteria  

## 6. Deployment
- Prepare deployment environment (staging, production)  
- Automate deployment with CI/CD tools  
- Conduct release readiness review  
- Rollout strategy (blue-green, canary, phased)  
- Post-deployment verification  

## 7. Operations & Maintenance
- Monitor system health and performance (APM, logging, alerts)  
- Incident management and troubleshooting  
- Apply security patches and updates  
- Continuous feedback loop for improvements  
- Plan for scaling, refactoring, or decommissioning  

---
**Note:** SDLC is iterative — feedback from later stages informs earlier stages for continuous improvement.
