## Key Concepts

### Probability Fundamentals
- **Sample spaces**: All possible outcomes
- **Events**: Subsets of sample space
- **Random variables**: Numerical outcomes
- **Expected value**: Average outcome
- **Variance**: Spread of distribution

### Stochastic Processes
- **Memoryless property**: Future independent of past
- **Stationary processes**: Statistics don't change over time
- **Ergodicity**: Time averages equal ensemble averages

### Applications in Computing
- Performance analysis
- Network modeling
- Machine learning algorithms
- Reliability engineering
- Simulation and Monte Carlo methods

## Learning Objectives

By the end of this course, you should be able to:
1. Compute probabilities for discrete and continuous distributions
2. Analyze Markov chains and predict long-term behavior
3. Model arrival processes using Poisson distributions
4. Design and analyze queueing systems
5. Build and reason with Bayesian networks
6. Apply probability to computer system performance analysis
