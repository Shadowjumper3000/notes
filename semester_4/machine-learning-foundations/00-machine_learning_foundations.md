## Key Concepts

### Machine Learning Pipeline
1. **Problem formulation**: Define the task
2. **Data collection**: Gather and prepare data
3. **Feature engineering**: Extract relevant features
4. **Model selection**: Choose appropriate algorithms
5. **Training**: Learn from data
6. **Evaluation**: Assess performance
7. **Deployment**: Put model into production

### Model Categories
- **Supervised learning**: Classification and regression
- **Unsupervised learning**: Clustering and dimensionality reduction
- **Reinforcement learning**: Learning through interaction

### Key Trade-offs
- **Bias-variance trade-off**: Simple vs complex models
- **Underfitting vs overfitting**: Too simple vs too complex
- **Training time vs accuracy**: Speed vs performance
- **Interpretability vs accuracy**: Explainability vs black-box
