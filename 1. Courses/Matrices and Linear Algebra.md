# Knowledge Map: Matrices and Linear Algebra

This course covers the fundamental mathematical foundations of linear algebra required for advanced machine learning, computer vision, and robotics. It focuses on the geometry of linear transformations and the numerical methods used to decompose and analyze matrices.

## Module 1: Vector Spaces and Linear Equations
### Session 1: [[2. Topics/Matrices And Linear Transformations/Vectors and Vector Spaces|Vectors and Vector Spaces]]
- Linear Combinations and Span
- Basis and Dimension
- Dot Products and Orthogonality

### Session 2: [[2. Topics/Matrices And Linear Transformations/Matrices and Linear Maps|Matrices and Linear Maps]]
- Matrix-Vector Multiplication
- Linear Transformations
- Rank and Nullity

### Session 3: Solving Linear Systems
- Gaussian Elimination
- Inverse Matrices
- Determinants

## Module 2: Matrix Decompositions
### Session 4: [[2. Topics/Matrices And Linear Transformations/Eigenvalues and Eigenvectors|Eigenvalues and Eigenvectors]]
- Characteristic Equations
- Diagonalization
- Spectral Theorem

### Session 5: [[2. Topics/Matrices And Linear Transformations/Singular Value Decomposition|Singular Value Decomposition (SVD)]]
- Geometry of SVD
- Low-Rank Approximation
- Principal Component Analysis (PCA) Connections

### Session 6: LU and QR Decompositions
- Matrix Factorization
- Gram-Schmidt Process
